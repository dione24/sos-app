# Nom du produit : Nafalan

Décision du 11 novembre 2026 : **Nafalan** est le nom choisi et validé par le
propriétaire du projet pendant cette intervention. Il remplace le nom visible
« SOS Sécurité Mali » pour le candidat 1.0.2.

## Source linguistique vérifiée

Le dictionnaire bambara Bamadaba donne l'entrée **nàfalan**, un nom défini par
« aide, secours, recours, appui ». La page a été consultée le **11 novembre 2026** :
[Bamadaba, lexique de la lettre n, entrée nàfalan](https://bamadaba.coastsystems.net/lexicon/n/).
L'entrée peut être retrouvée en recherchant « recours » sur cette page ; la
marque tonale peut empêcher une recherche textuelle simple de « nafalan ».

La graphie du produit est **Nafalan**, sans marque tonale. Le lien entre ce sens
lexical et une application d'aide en situation d'urgence motive le choix du nom.
Cette interprétation éditoriale ne constitue ni une certification linguistique
de tous les textes de l'application, ni une validation de son contenu médical.

## Portée du changement

Le nouveau nom apparaît dans la configuration d'affichage de l'application,
les écrans et les documents de présentation courants. Les rapports de livraison
antérieurs conservent « SOS Sécurité Mali » pour identifier correctement les
versions et les observations auxquelles ils se rapportent.

Le renommage conserve les identifiants techniques suivants afin de poursuivre
le même projet et de retrouver ses données locales :

| Élément | Valeur conservée |
| --- | --- |
| Application Android et identifiant iOS | `ml.sossecurite.app` |
| Slug Expo | `sos-securite-mali` |
| Schéma de liens | `sosmali` |
| Base locale | `sos-securite-mali-secure-v2.db` |
| Identifiant SecureStore de la clé SQLCipher | `sos_mali_database_key_v1` |
| Alias Android Keystore de signature mesh | `sos_mali_mesh_origin_signing_v1` |
| Format d'export médical existant | `sos-mali-medical-v2` |

Les anciennes URL de politique de confidentialité, chemins d'assets et noms de
fichiers compatibles peuvent également garder le nom historique. Le nom visible
n'impose pas de réécrire ces identifiants ni de générer de nouvelles clés.
La conservation réelle des données après mise à jour doit être contrôlée sur
une installation Android chiffrée de recette ; les tests SQLite en mémoire ne
suffisent pas à le prouver.

## Disponibilité du nom

Une recherche dans Google Play, l'App Store ou un moteur de recherche peut
relever des applications portant un nom voisin. Ses résultats ne constituent
pas une preuve de disponibilité ni d'enregistrement comme marque. Ce document
ne revendique aucune exclusivité, aucun dépôt de marque ni aucune validation
juridique du nom Nafalan.

Le choix utilisateur est une décision de nommage du projet. La publication sous
ce nom et son acceptation éventuelle par les stores restent des étapes distinctes.
